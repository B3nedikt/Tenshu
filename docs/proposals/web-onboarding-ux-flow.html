§7.1 — State commit gate
IndexedDB is not committed until §4b.4 succeeds. A user who closes the tab between §4b.2 and §4b.4 leaves no trace; §2 routes them back to §4.0.
§7.5 — Multi-tab race
First tab to commit IDB state wins; later tabs detect state and re-route to §3 Locked.
§7.2 — Passphrase fallback
If WebAuthn unsupported, §4a.4 / §4b.5 swap to a passphrase screen (Argon2id-derived, strength meter). Recovery-phrase-only mode if Argon2id also unsupported.
§7.6 — Recovery network retry
Relay unreachable in §6.2 → retry only the relay fetch. Argon2id derivation is cached so a flaky network doesn't repeat the 5s wait.
Open: §10 i18n
Recovery uses the BIP-39 English wordlist. Localising means showing English with a translation note, or per-locale wordlists (which complicates cross-locale recovery).
