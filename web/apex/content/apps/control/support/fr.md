## Premiers pas {#get-started}

Tout commence avec Tenshu Control. L’appli crée votre realm, l’espace privé que partagent vos
applis Tenshu. Elle conserve vos clés et relie vos appareils. Les autres applis Tenshu, comme
Tenshu Drive, ont besoin que Control soit configuré sur le même appareil.

::: ios
1. **Installez Tenshu Control** depuis l’App Store, puis ouvrez-le.
   ![Écran d’accueil de Tenshu Control sur iPhone, avec les boutons « Start fresh on this device », « I have Tenshu on another device » et « Recover from a recovery phrase »](shot:01-welcome)
2. **Créez votre realm.** Touchez **Start fresh on this device** (Repartir de zéro sur cet
   appareil), puis **Continue** (Continuer). Tenshu protège vos clés avec le stockage sécurisé de
   cet iPhone : vous n’avez aucun mot de passe à retenir.
   ![Écran « Protected by your device » (Protégé par votre appareil) de Tenshu Control, avec un bouton « Continue »](shot:02-protected)
3. **Conservez votre phrase de récupération.** Control affiche maintenant **You're set up** (Tout
   est prêt) et votre phrase de récupération. Notez les 24 mots et gardez-les en lieu sûr, hors
   ligne.
   ![Tenshu Control affichant « You're set up », avec un lien « Turn on sync » au-dessus des 24 mots de la phrase de récupération et un bouton « I've saved it »](shot:03-recovery-phrase)
4. **Activez la synchronisation.** Sur le même écran, touchez **Turn on sync** (Activer la
   synchronisation) et saisissez votre adresse e-mail pour obtenir votre offre de stockage ; un
   nouveau compte commence avec l’offre gratuite. D’ici là, tout reste sur cet iPhone. Touchez
   ensuite **I've saved it** (Je l’ai notée). Vous pouvez aussi activer la synchronisation plus
   tard, dans **Settings** (Réglages) → **Storage** (Stockage).
   ![Écran « Sign in or create your free Tenshu account » (Connectez-vous ou créez votre compte Tenshu gratuit) de Tenshu Control, avec un champ e-mail](shot:08-sign-in)
5. **Ajoutez votre autre appareil.** Installez-y Tenshu Control et choisissez **I have Tenshu on
   another device** (J’ai Tenshu sur un autre appareil). Sur cet iPhone, allez dans **Settings** →
   **Add a device** (Ajouter un appareil). L’un des appareils affiche un code et l’autre le scanne.
   Vérifiez que les deux affichent le même code de confirmation, puis confirmez.
   ![Écran « Add a device » de Tenshu Control sur « Show a code » (Afficher un code), avec un QR code et un code d’association](shot:09-add-device)
:::

   peut être visible par d’autres. Tenshu vérifie ensuite que vous l’avez bien conservée.

   (Appareils) → **Pair a new device** (Associer un nouvel appareil). Le code d’association expire
   au bout de 5 minutes. Vérifiez que les deux appareils affichent le même code de confirmation.
   ![La boîte de dialogue « Pair a new device » avec un code d’association](shot:09-add-device)

## Comment Tenshu Control protège la confidentialité de vos données {#privacy}

- **Vos clés sont créées sur vos appareils et ne les quittent jamais en clair.** Quand vous
  ajoutez un appareil, votre appareil existant chiffre les clés pour le nouveau avant qu’elles ne
  transitent par notre serveur. Le serveur ne voit jamais que des données qu’il ne peut pas
  déchiffrer. {source: docs/sync/threat-model.md | Modèle de menace, actifs A1 et A4 (clés)}
  {source: docs/whitepaper.adoc | Livre blanc, ajouter un appareil}
- **Les serveurs de Tenshu ne peuvent pas lire vos données.** Ils ne transmettent et ne stockent
  que des données chiffrées. Ils voient toutefois certains faits dont ils ont besoin pour
  fonctionner : la quantité de données que vous stockez, le nombre de vos appareils et le moment
  où ils se synchronisent. {source: docs/sync/threat-model.md | Modèle de menace, invariant I1, actif A6 (métadonnées) et T-T-07}
  {source: AGENTS.md | House Rule 1 : le relais ne voit que du texte chiffré}
- **Votre phrase de récupération n’appartient qu’à vous.** Vos clés sont dérivées de ses 24 mots.
  Personne d’autre n’en détient de copie : personne, pas même nous, ne peut restaurer votre realm
  sans elle. Quiconque la possède peut tout ouvrir, alors gardez-la hors ligne. {source: docs/sync/threat-model.md | Modèle de menace, actif A9 (code de récupération), invariant I7 et T-RC-01}
- **Vous pouvez utiliser Tenshu sans compte.** Sur un seul appareil, Tenshu fonctionne sans
  compte et n’envoie rien à nos serveurs. Pour synchroniser, vous choisissez une offre de
  stockage : l’offre gratuite demande une adresse e-mail, un code d’activation n’en demande aucune. {source: docs/adr/0019-storage-capacity-gating.md | ADR 0019, capacité de stockage : sans abonnement, aucun trafic vers le relais}
  {source: docs/proposals/commerce-accounts-and-sessions.md | Comptes commerce : utiliser un code ne demande pas d’e-mail}

## Problèmes courants {#problems}

### J’ai perdu mon téléphone, ou tous mes appareils

S’il vous reste un appareil dans votre realm, utilisez-le pour ajouter votre nouvel appareil. S’il
ne vous en reste aucun, installez Tenshu Control sur un nouvel appareil et choisissez **Recover
from a recovery phrase** (Restaurer à partir d’une phrase de récupération). Saisissez vos 24 mots.
L’appareil restauré devient votre seul appareil ; ajoutez de nouveau les autres à partir de lui.

Sans la phrase de récupération et sans aucun de vos appareils, personne ne peut récupérer vos
données, pas même nous.

### Tenshu affiche « This device doesn't have your recovery phrase »

Ce message (« Cet appareil ne possède pas votre phrase de récupération ») est normal sur un
appareil ajouté par association. Seul l’appareil qui a créé votre realm, ou un appareil configuré
avec la phrase, en garde une copie. Ouvrez **Recovery Phrase** (Phrase de récupération) sur cet
appareil-là.

### Les codes de confirmation ne correspondent pas quand j’ajoute un appareil

Arrêtez-vous et ne confirmez pas. Annulez sur les deux appareils, vérifiez qu’ils utilisent tous
les deux la dernière version de Tenshu Control, puis recommencez.

### J’ai ajouté un appareil mais rien ne se synchronise

Si Tenshu Control affiche **Nothing will sync yet** (Rien ne sera encore synchronisé), votre realm
n’a pas d’offre de stockage : les modifications restent donc sur chaque appareil. Rien n’est
perdu. Choisissez une offre dans **Services**, ou dans **Storage** (Stockage) sur iPhone.

::: ios
Dans **Settings** (Réglages), un realm sans offre apparaît comme **Local only** (Local
uniquement).
:::

::: ios android macos
### J’ai oublié ma phrase secrète

Si vous avez ajouté une phrase secrète (passphrase), elle ne peut pas être réinitialisée. C’est
votre phrase de récupération qui restaure votre realm : choisissez **Recover from a recovery
phrase** (Restaurer à partir d’une phrase de récupération) sur cet appareil.
:::

::: web
### J’ai effacé les données de mon navigateur

Tenshu conserve les clés de ce navigateur dans les données du site. Si vous les effacez, ce
navigateur ne fait plus partie de votre realm. Vos autres appareils ont toujours vos données.
Choisissez **I have Tenshu already** (J’ai déjà Tenshu) sur [tenshu.app/start](/start) pour
ajouter de nouveau ce navigateur, ou restaurez avec votre phrase de récupération.
:::

## Configuration requise {#requirements}

::: ios
- iOS 16 ou version ultérieure, sur iPhone ou iPad.
:::

::: android
- Android 7.0 ou version ultérieure.
:::

::: macos
- Un Mac. Tenshu Control fonctionne dans la barre des menus.
:::

::: web
- Un navigateur web récent.
- Tenshu conserve ses clés dans les données de site de votre navigateur : ne les effacez donc pas
  pour tenshu.app.
:::

- Pour synchroniser entre appareils : une offre de stockage. L’offre gratuite comprend 5 Go.

## Contact {#contact}

Écrivez à [support@tenshu.app](mailto:support@tenshu.app). Indiquez-nous l’appli et l’appareil
que vous utilisez, et ce que vous voyez à l’écran.

**L’assistance ne vous demandera jamais votre phrase de récupération.** Personne chez Tenshu n’en
a besoin, jamais. Quiconque la possède peut tout ouvrir dans votre compte.
