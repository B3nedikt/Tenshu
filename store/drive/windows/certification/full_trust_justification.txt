Tenshu Drive is a desktop (Win32) file-management application packaged with MSIX; runFullTrust is the capability every packaged desktop app needs to run. It is written in Kotlin and runs on a Java runtime bundled in the package. It connects to Tenshu Control on the same PC over a local socket in the user's profile and requires Control to be installed. All files are encrypted on the device before they leave it; our servers cannot read them. The app does not install drivers or services, does not require administrator rights, and writes only to the user's profile.
