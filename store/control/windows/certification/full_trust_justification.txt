Tenshu Control is a desktop (Win32) application packaged with MSIX; runFullTrust is the capability every packaged desktop app needs to run. It is written in Kotlin and runs on a Java runtime bundled in the package. Control stays resident to sync the user's end-to-end-encrypted data between their own devices, shows a notification-area icon through a small companion process in the same package, and serves the other Tenshu apps (such as Tenshu Drive) over a local socket in the user's profile. When the user turns it on, it registers a Tenshu Drive folder with the Windows cloud files API so their files appear in File Explorer. All user data is encrypted on the device before it leaves it; our servers cannot read it. The app does not install drivers or services, does not require administrator rights, and writes only to the user's profile.
